# Logička kola sa MOS tranzistorima — 2. deo

Izvor: `../09 2 MOS logicka kola.pdf`, 31 PDF strana i 62 slajda.
Poreklo: Digitalna elektronika 1, 2021/22, Katedra za elektroniku, prof. dr Lazar Saranovac.

Svih **62/62 slajda** rekonstruisano je i pojedinačno sadržinski i vizuelno pregledano.

```sh
make -C predavanja LECTURE=09_2_mos_logicka_kola all
make -C predavanja LECTURE=09_2_mos_logicka_kola check
make -C predavanja LECTURE=09_2_mos_logicka_kola review
```

Izlaz: `build/09_2_mos_logicka_kola.pdf`. Sve šeme, preseci, karakteristike i
vremenski dijagrami imaju uređive TikZ izvore, a formule i međukoraci LaTeX izvore.
Sačuvani su originalni indeksi, greške, nepotpuna zagrada i veze ka dokumentima.
`kodovi/provera_logike.py` bez dodatnih biblioteka izvršava 179 računskih provera.
Greške originala navedene su u `provera/uocene_greske.md`.
