\begin{frame}[label=02-s007]{Sinteza i minimizacija kombinacionih mreža}
Mada se najčešće kod sinteze kombinacionih mreža pod \alert{minimizacijom} podrazumeva minimizacija
\begin{itemize}
\item broja upotrebljenih logičkih kola,
\item broja ulaza u logička kola
\end{itemize}
\vspace{4mm}
isto tako se može govoriti i o minimizaciji
\begin{itemize}
\item broja upotrebljenih \alert{komponenti}
\item ukupnog kašnjenja signala od ulaza do izlaza
\item \ldots
\end{itemize}
\end{frame}
