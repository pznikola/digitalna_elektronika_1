# 06 — Kodovi

prof. dr Lazar Saranovac; podaci su preuzeti sa originala.

Status: **30/30 slajdova rekonstruisano i pojedinačno pregledano**.
Izgradnja i završna provera iz korena repozitorijuma:

```sh
make -C predavanja LECTURE=06_kodovi all
make -C predavanja LECTURE=06_kodovi check
make -C predavanja LECTURE=06_kodovi review
```

PDF: `build/06_kodovi.pdf`. Uporedni pregled: `build/pregled/index.html`.

Inventar i aktuelne potvrde su u `provera/mapa.json` i `provera/pregled.json`.
